# Convivência

Esta é uma comunidade de aprendizagem. Trate dúvidas com respeito, explique contextos e evite julgamentos sobre experiência prévia. Não publique dados pessoais de outras pessoas, conteúdo discriminatório ou ataques.

Mantenha issues e revisões centradas no comportamento observado, com exemplos reproduzíveis. Críticas ao trabalho são bem-vindas quando ajudam a melhorar o recurso. Para conteúdo sensível, use os canais apropriados em vez de expor pessoas publicamente. A moderação cabe ao mantenedor do repositório.

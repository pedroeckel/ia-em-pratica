# Relatar um problema de segurança

Não publique credenciais, dados pessoais ou uma exploração contendo informação privada em uma issue. Para vulnerabilidades deste repositório, use o [canal privado do GitHub](https://github.com/pedroeckel/ia-em-pratica/security/advisories/new). Para um recurso externo, use o canal de segurança do fornecedor.

Os selos do catálogo descrevem testes funcionais com limites; não significam auditoria de segurança. O CI valida arquivos e exemplos locais, sem executar MCPs, hooks ou instaladores de terceiros. O instalador não pede credenciais nem substitui automaticamente conteúdo já existente.

Versão inicialmente mantida: 0.1.x. Não há SLA de suporte ou recompensa por vulnerabilidades declarados.
